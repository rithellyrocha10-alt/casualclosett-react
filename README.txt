
CasualClosett_ - HTML Template (local)
-------------------------------------
Como usar:
1. Descompacte o arquivo e abra 'index.html' no navegador.
2. Para ativar o WhatsApp, edite 'app.js' e substitua WHATSAPP_NUMBER pela sua string no formato 55DDDNÚMERO.
3. Troque as imagens em /assets por suas fotos (mantenha os nomes ou ajuste os paths em app.js).
4. Para editar produtos, abra app.js e altere o array PRODUCTS.

Conteúdo deste ZIP:
- index.html
- styles.css
- app.js
- /assets (hero.jpg, product1.jpg, product2.jpg, product3.jpg)
